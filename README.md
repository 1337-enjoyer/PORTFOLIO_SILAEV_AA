### 🛠️ Проект 2 — [Learn Platform]

> Learn Platform — учебная веб-платформа на Django для подготовки к техническим собеседованиям. Проект объединяет структурированные статьи по программированию (Python, PostgreSQL, Git, алгоритмы) и интерактивные тесты с перемешиванием вопросов, мгновенной проверкой и детальным разбором ошибок. Реализованы иерархия «тема → подтема → статья → тест», адаптивный интерфейс, подсветка кода через Markdown + Pygments и система фикстур для быстрого развёртывания контента.

- **Репозиторий:** [[ссылка на GitHub]](https://github.com/1337-enjoyer/LearnWay)
